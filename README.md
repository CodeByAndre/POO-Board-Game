# Metro de Lisboa - jogo de tabuleiro (POO, UAL 2026-2027)

Jogo de tabuleiro para dois jogadores, em Java, na consola.

## Requisitos

Java (confirmar a versão usada no IntelliJ e indicá-la aqui).

## Compilar

    javac -encoding UTF-8 -d out $(find src -name "*.java")

## Correr

    java -cp out console.Main

## Testes

    java -cp out tests.JogoChecks
